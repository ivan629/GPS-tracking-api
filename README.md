# GPS-tracking-api

Node/Express API for the GPS tracking app, written in modern JavaScript and compiled with Babel. Companion to [GPS-tracking-client](https://github.com/ivan629/GPS-tracking-client) and [gps-pwa-tracking-portal](https://github.com/ivan629/gps-pwa-tracking-portal).

## Development

```bash
npm install
npm run dev      # nodemon + babel-node
npm run lint
npm start        # build to dist/ and run
```
